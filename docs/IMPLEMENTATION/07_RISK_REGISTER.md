# Risk Register

Probability/impact are planning assessments, not measured frequencies. Review weekly; high risks have a named owner role, trigger and fallback. Risk owner is responsible for updating status and evidence.

## Review cadence

- Review high/critical risks at each weekly milestone and before any data/model/feature gate.
- A risk is not closed because code compiles; require the trigger test, evidence link and reviewer.
- Escalate immediately if a risk affects privacy, physical response, evidence integrity, data loss, or a material public claim.
