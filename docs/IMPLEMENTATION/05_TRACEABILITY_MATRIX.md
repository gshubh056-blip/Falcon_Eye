## Traceability rules

- Keep exact PRD requirement IDs and TRD/API IDs; do not create substitute IDs when the canonical ID exists.
- `PPT-xx` facts and keyword-level rows are traced separately in [10_PPT_COVERAGE_MATRIX.md](./10_PPT_COVERAGE_MATRIX.md).
- If an API, table, screen, worker, task, or test is not yet defined, record a named gap here and in [00_CONFLICTS_AND_DECISIONS.md](./00_CONFLICTS_AND_DECISIONS.md), not an empty cell.
- A test ID is a planned test until its result and reproducible evidence are checked in.
